# mongodb_badge_basics

## Some key differences include : 
Relational databases(like mysql) using structured tables with schemas,
while databases like MongoDB store flexible (JSON) documents. MongoDB allows for dynamic data models
making it easier to contain unstructured or changing data compared to MySQL fixed schema.

## A healthcare scenario could be :

a non SQL database like MongoDB used for storing ehrs from
different hospitals. It would be able to contain data in different formats like lab results, consult
notes, and radiology images, without needing a fixed structure. Different hospitals may record data
differently and mongoDB flexible structure makes it easier to store all that information in one location.
